# Mania Object Unlocker for Anbernic ARM64

ARM64 build of Mania Object Unlocker for the Sonic Mania decompilation.

The GitHub Actions workflow builds the mod from the upstream source and publishes the ARM64 library and packaged mod as a GitHub Release.

Upstream source:
https://github.com/MegAmi24/Mania-Decomp-Mods

For the Steam-style Sonic Mania decompilation, this build uses RETRO_REVISION=2 and GAME_VERSION=6.
